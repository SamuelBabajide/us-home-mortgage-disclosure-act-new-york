US HMDA 2022 to 2025 · SQL Playground

1,754,846 mortgage applications from New York State, in sixteen tables, running in your browser. Nothing is installed and nothing is sent to a server.

Starting the database engine…

Edit anything here and press Ctrl + Enter to run it. Your changes live in this browser tab only. Picking another query from the list, or reloading the page, brings the original back.

The engine is DuckDB compiled to WebAssembly, served from this site rather than a CDN. The data is 53 MB of Parquet in nineteen files, one per table and one per year of the fact table. All nineteen are downloaded once when the page loads and held in this tab, so a query costs no network at all. Reading the files in place with HTTP range requests was tried and abandoned: GitHub Pages serves them gzipped, which makes a byte range address the compressed stream rather than the file.

Schema and view names match the PostgreSQL build exactly, so every query here is the query printed in the project README, unedited. A parity test in the repository runs all forty-two against both engines, plus the three labelled views, and fails on any difference.
